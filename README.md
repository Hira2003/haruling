# HaruLing 💜

**Learn programming, one small step at a time.**

HaruLing is a gamified programming-learning app. This repository starts the web-first MVP, built with React and Vite, with an Android packaging path planned through Capacitor.

## Current MVP
- A welcoming learning dashboard
- A beginner-friendly JavaScript course path
- Interactive multiple-choice lessons
- XP, hearts, streak and progress stored locally in the browser
- Responsive layout for desktop and mobile

## Tech stack
- React
- Vite
- JavaScript
- CSS (custom design system; no UI framework yet)

## Run locally
Requires a current Node.js release supported by Vite.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Project structure
```
src/
  components/   Reusable interface components
  data/         Course and lesson content
  pages/        App screens
  App.jsx
  main.jsx
  index.css
```

## Roadmap
1. Build and refine the learning experience.
2. Add more programming courses and question types.
3. Add authentication and cloud progress with Supabase.
4. Add Android packaging with Capacitor.

HaruLing is an original learning project inspired by the general idea of gamified education. It is not affiliated with Duolingo.
